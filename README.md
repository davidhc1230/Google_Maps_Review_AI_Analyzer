# Google Maps Review Analysis

Using automated tools to scrape Google Maps reviews, and employing natural language processing techniques to "aggregate subjective reviews into objective analyses," thereby helping users gain a more comprehensive understanding of the review content. Additionally, a conversational feature is provided, allowing users to further inquire about the reviews, obtain specific information, or perform more in-depth analysis.

<br>

透過自動化工具爬取 Google Maps 評論，並使用自然語言處理技術嘗試「將主觀的評論，匯聚為客觀的分析」，從而幫助使用者更全面地理解評論內容。另外也提供了對話功能，允許使用者針對評論進行進一步提問，獲取特定的資訊，或實現更深入的分析。
